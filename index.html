Fundamentação Teórica e Fisiologia de Protocolo

Estudo aprofundado sobre camadas de transporte, evasão de firewalls e bases legais.

Ciclo de Vida do Handshake TCP/IP e RFC 793

O Protocolo de Controle de Transmissão (TCP) é orientado à conexão. A tabela abaixo resume como o kernel responde a cada estado de porta segundo as regras da RFC 793 / RFC 9293:

Estado de Porta Comportamento do Kernel / Firewall Resposta Observada no Fio
Aberta (Open) Processo ativo escutando na porta; chamada accept() aguardando conexão. TCP [SYN, ACK] ou resposta direta da aplicação.
Fechada (Closed) Host online; kernel recebe o pacote mas não há processo ouvindo na porta destino. TCP [RST, ACK] ou ICMP Type 3 Code 3 (UDP).
Filtrada (Filtered) Firewall com/sem estado descarta ou bloqueia o pacote de auditoria. Ausência de resposta (Timeout) ou ICMP Type 3 Code 1/2/9/10/13.

Técnicas de Varreduras Clássicas vs. Stealth

TCP Connect Scan (-sT)

Executa o handshake de 3 vias completo usando a syscall connect() do sistema operacional. É extremamente barulhento porque obriga o sistema de destino a logar a conexão completa no nível de aplicação.

Handshake Completo

TCP SYN Stealth Scan (-sS)

Varredura semi-aberta. O scanner envia um SYN, espera o SYN-ACK, mas responde imediatamente com um pacote RST (reset) antes que o handshake termine. O daemon do serviço alvo nunca é notificado, escapando dos logs tradicionais.

Semi-Aberto

Scans Inversos (Evasão baseada em RFC)

Ao explorar o comportamento diferencial entre pilhas TCP de sistemas Linux/BSD (que seguem estritamente a RFC 793) e pilhas Windows, os seguintes tipos de scan são usados para burlar regras de detecção:

  • TCP NULL Scan (-sN): Envia um pacote com as flags TCP totalmente zeradas (0x00).
  • TCP FIN Scan (-sF): Envia apenas a flag FIN ativada, simulando um fechamento prematuro de sessão.
  • TCP Xmas Scan (-sX): Envia as flags FIN, PSH e URG ligadas ao mesmo tempo, brilhando como uma árvore de natal na inspeção visual.

Aspectos Jurídicos e Governança Forense

Atenção Legista/Ética: No Brasil, as atividades de varredura ativa de portas devem ser pautadas por limites contratuais claros (Rules of Engagement - RoE) para não ferirem leis de proteção ou crimes cibernéticos.

Código Penal Brasileiro (Art. 154-A)

O simples envio de pacotes de testes para mapear portas abertas (camada L4) não perfaz o tipo penal de "invasão de dispositivo informático". Porém, a execução de exploits automatizados, injeções ou força bruta sem autorização configura tentativa ou consumação do delito.

LGPD (Lei 13.709/2018) e Marco Civil

Varreduras profundas que realizam a extração de identidades ou mapeamento de dados corporativos lidam diretamente com o tratamento de informações corporativas e dados pessoais. Conexões locais no laboratório estão seguras de tais enquadramentos legais por estarem restritas ao host local.

Toolkits do Laboratório Ofensivo

Guia de referência didático das ferramentas sugeridas para os desafios do Net-Scan Lab, incluindo instruções de instalação para Kali Linux.

NMAP

Nmap (Network Mapper)

🎯 CTFs: Desafios 1-20, 31-40, 61-75, 126-130 📥 Instalação: Pré-instalado (ou sudo apt install nmap)

A ferramenta padrão de varredura ativa de redes. Utilizada para mapear portas abertas, serviços e versões.

⚡ Comandos Essenciais
  • nmap -sS -p 9001-9009 127.0.0.1: SYN scan (Stealth) nas portas do laboratório.
  • nmap -sV -p 9001 127.0.0.1: Detecção de versão do serviço na porta FTP.
  • nmap --script=vuln 127.0.0.1: Varredura com scripts NSE automáticos de vulnerabilidade.
RUSTSCAN

RustScan

🎯 CTFs: Desafios 1-20, 101-104 (Varredura Veloz) 📥 Instalação: sudo apt update && sudo apt install rustscan

Um scanner de portas moderno e extremamente veloz baseado em Rust, capaz de escanear 65535 portas em segundos.

⚡ Comandos Essenciais
  • rustscan -a 127.0.0.1 -- -sV: Varredura ultrarrápida combinada com detecção de versão do Nmap.
  • rustscan -a 127.0.0.1 -p 9000-9500: Varredura de range de portas específico em milissegundos.
NETCAT

Netcat (nc)

🎯 CTFs: Desafios 21-30, 101-110, 117-121 📥 Instalação: Pré-instalado (ou sudo apt install netcat-openbsd)

O "canivete suíço" das redes. Permite abrir conexões TCP/UDP cruas para envio de comandos interativos ou Banner Grabbing.

⚡ Comandos Essenciais
  • nc 127.0.0.1 9002: Conexão interativa à porta de chat ou shell reversa.
  • nc -nv 127.0.0.1 9001: Banner grabbing do servidor FTP simulado com IP numérico direto.
  • nc -u 127.0.0.1 9009: Envio de pacotes interativos para a porta de escuta UDP.
FFUF

Ffuf (Fuzz Faster U Fool)

🎯 CTFs: Desafios 81-100, 131-150 📥 Instalação: sudo apt update && sudo apt install ffuf

Fuzzer web escrito em Go, perfeito para localizar caminhos de desenvolvimento vazados e diretórios/arquivos sensíveis.

⚡ Comandos Essenciais
  • ffuf -u http://127.0.0.1/FUZZ -w /usr/share/wordlists/dirb/common.txt: Fuzzing básico de rotas.
  • ffuf -u http://127.0.0.1/FUZZ -w wordlist.txt -mc 200,301: Filtra apenas respostas com status HTTP 200 ou 301.
  • ffuf -u http://127.0.0.1/FUZZ -w list.txt -fs 120: Filtra e oculta respostas de tamanho específico (exclui falsos 404).
GOBUSTER

Gobuster & DirBuster

🎯 CTFs: Desafios 81-100, 131-150 (Alternativas de Fuzzing) 📥 Instalação: sudo apt install gobuster dirbuster

Ferramentas de descoberta de diretórios e nomes de arquivo com suporte a multi-threads. O DirBuster possui interface gráfica (GUI).

⚡ Comandos Essenciais
  • gobuster dir -u http://127.0.0.1/ -w /usr/share/wordlists/dirb/common.txt: Varredura de subpastas web.
  • gobuster dir -u http://127.0.0.1/ -w wordlist.txt -x php,txt,html: Busca rotas forçando extensões.
  • Use dirbuster no terminal do Kali para abrir a interface visual amigável de fuzzing.
WIRESHARK

Wireshark & Tshark

🎯 CTFs: Desafios 41-60 (Análise de Tráfego) 📥 Instalação: Pré-instalado (ou sudo apt install wireshark tshark)

Analisador e sniffer gráfico do tráfego local de rede. Permite inspecionar os detalhes de handshakes, portas e cabeçalhos IP.

⚡ Filtros Úteis
  • tcp.port == 9002: Filtra apenas conexões no Netcat interativo do lab.
  • tcp.flags.syn == 1 and tcp.flags.ack == 0: Isola pacotes SYN de escaneamento de portas.
  • ip.addr == 127.0.0.1: Mostra apenas tráfego local de loopback.
HPING3

Hping3

🎯 CTFs: Desafios 61-75, 126-130 (Pacotes Modificados) 📥 Instalação: Pré-instalado (ou sudo apt install hping3)

Utilitário de crafting manual de pacotes. Perfeito para alterar flags e portas de origem para testar evasões de firewall.

⚡ Comandos Essenciais
  • sudo hping3 -F -P -U -p 9001 127.0.0.1: Envia pacotes Xmas personalizados para a porta FTP.
  • sudo hping3 -S -p 9001 -s 53 127.0.0.1: Envia pacote SYN com porta de origem alterada para 53 (Bypass).
CURL

Curl & Wget

🎯 CTFs: Desafios 115, 116, 122, 123 (Requisições HTTP) 📥 Instalação: Pré-instalado (ou sudo apt install curl wget)

Clientes HTTP via linha de comando úteis para enviar cookies, alterar cabeçalhos de navegador e testar respostas Web.

⚡ Comandos Essenciais
  • curl -A "Admin-Browser" http://127.0.0.1/: Faz requisição alterando o User-Agent.
  • curl -b "admin=true" http://127.0.0.1/: Envia um Cookie customizado via cabeçalho.
  • curl -X POST -d "param=value" http://127.0.0.1/: Envia parâmetros em lote via POST.
NIKTO

Nikto

🎯 CTFs: Desafios 81-100 (Scanner de Vulnerabilidade Web) 📥 Instalação: sudo apt update && sudo apt install nikto

Scanner de vulnerabilidade web simples que pesquisa por caminhos de arquivos de backup perigosos ou configurações incorretas.

⚡ Comandos Essenciais
  • nikto -h http://127.0.0.1/: Executa uma varredura geral e agressiva contra o servidor web local.
  • nikto -h http://127.0.0.1/ -p 8080: Permite mapear portas alternativas do laboratório.
